# Dev — Demo Onboarding

## Proposito
Agente de desenvolvimento do projeto **demo-onboarding**. Executa tarefas de
codigo e arquivos via runtime `task.run.dev`.

## Acoes tipicas

| Acao | Uso |
|------|-----|
| read_file | Ler codigo ou docs |
| write_file | Criar ou sobrescrever arquivos |
| edit_file | Patch em arquivo existente |
| list_directory | Explorar estrutura |
| run_tests | Executar pytest |
| get_capabilities | Listar acoes disponiveis |

## Diretorio de trabalho
Raiz do repositorio AFP (`working_dir: "."` em `project.json`).
